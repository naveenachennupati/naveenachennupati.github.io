PROJECT 01
DETECTION ENGINEERING · SOC

Identity Threat Detection for Microsoft Sentinel

From noisy authentication signals to correlated investigation candidates.

THE PROBLEM

Authentication noise creates review burden, while password spraying and suspicious sign-in sequences require careful correlation.

THE OUTCOME

A controlled 280-scenario / 2,180-event benchmark reduced candidate alerts by 54.5% against a volume-based baseline while preserving 80% scenario recall in the reference logic.

220 → 100review candidates in controlled replay

PROJECT 02
IDENTITY SECURITY · GOVERNANCE

Microsoft Entra ID & Azure Access Governance

Turning scattered privileged permissions into an accountable review workflow.

THE PROBLEM

Privileged access, guest permissions, service principal credentials, and broad RBAC assignments are difficult to assess consistently without a unified review queue.

THE OUTCOME

An evaluation using 2,000 generated users and 376 role/credential records surfaced 138 distinct first-pass review items, with 119 principals requiring potential reviewer outreach.

138 / 376records flagged for initial review

ⓘ Generated identities and entitlements; no live tenant certification performed.

PROJECT 03
VULNERABILITY MANAGEMENT · RISK

Exploitation-Aware Vulnerability Prioritization

Moving beyond severity-only queues to defensible remediation priorities.

THE PROBLEM

CVSS-only remediation rules can overlook known-exploited weaknesses when their numerical severity falls below a fixed review threshold.

THE OUTCOME

In a deliberately modeled 240-observation comparison using seven selected real KEV-positive CVEs, 80 observations fell below the CVSS 7 threshold—illustrating where severity-only triage would miss cases.

80 / 240modeled observations below CVSS 7

ⓘ Selected real KEV entries; all asset/scan characteristics are modeled, not production scans.
