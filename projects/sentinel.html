01 / SECURITY PROBLEM

The challenge

Authentication noise creates review burden, while password spraying and suspicious sign-in sequences require careful correlation.

02 / SOLUTION DESIGN

The approach

Authored four MITRE-mapped KQL detection rules, Azure Bicep rule definitions, triage guidance, Python reference checks, and version-controlled regression tests.

03 / MEASURABLE FINDING

What the evidence shows

A controlled 280-scenario / 2,180-event benchmark reduced candidate alerts by 54.5% against a volume-based baseline while preserving 80% scenario recall in the reference logic.

04 / OPERATIONAL DECISION

What this informs

Prioritize correlated identity events for analyst review, while explicitly tracking low-and-slow detection gaps and shared-proxy ambiguity.
