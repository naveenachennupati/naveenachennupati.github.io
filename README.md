# Naga Naveena Chennupati — Professional Cybersecurity Portfolio

**Live URL (after GitHub Pages is enabled):** https://naveenachennupati.github.io/

A complete professional website covering **About, Work Experience, Measured Career Scope, Skills, Three Security Engineering Projects, Nine IEEE Publications, Education, and Contact**. It is designed as a professional career portfolio, not just a list of personal repositories.

## Included

- `index.html` — complete responsive single-page professional portfolio with 7 sections
- `research.html` — all nine IEEE conference publications with supplied IEEE Xplore links
- `projects/*.html` — detailed engineering case studies: problem, solution, measured finding, decision and evidence
- `evidence/*` — reproducible project reports and associated data from the prepared security projects
- `downloads/*` — application resume, master resume and engineering case-study PDF
- `assets/*` — editable SVG visuals, consistent with the GitHub profile README
- `style.css` and `script.js` — original mobile-responsive, accessible front-end; no dependencies or build step
- `.nojekyll` — simple GitHub Pages deployment

### Evidentiary boundaries

Employment scope metrics (150+ weekly alerts, 30+ quarterly incidents, 2,000+ identities) were provided by the portfolio owner. Project benchmark figures were reproduced from constructed scenario exercises and **must not be presented as production incident reduction, employer ROI, verified cloud execution, or actual vulnerability scan findings**. The source repositories and evidence reports document the methods and limitations. No employer data is included.

- Professional details: `index.html`
- Research papers and links: `research.html`
- Project case studies: `projects/*.html`
- Style and colors: `style.css`
- Optional portrait: Add a real photo only with your permission; this version uses an abstract graphic to avoid representing a fictional headshot as genuine
- Resume files: replace the corresponding PDFs in `downloads/`

Do not upload private employer data, logs, credentials or internal ticket screenshots.
